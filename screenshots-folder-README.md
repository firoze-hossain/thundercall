# Screenshots

The main [`README.md`](../../README.md) references four images from
this folder. It links to them by these exact filenames, so dropping a
PNG in here with the matching name is all it takes for it to show up
— no other edits needed.

| File | What to capture |
|---|---|
| `01-request-response.png` | The main request-builder screen: a real request (method, URL, headers) with a successful response showing in the body — a 2xx status looks great here. |
| `02-collections.png` | The sidebar with a collection expanded into folders and requests, showing the "organized like a filesystem" structure. |
| `03-editor.png` | The raw body editor showing off the recent editor work — line numbers down the left edge and a `//` comment rendered in its grey/italic color are the two easiest to capture in one shot. |
| `04-highlights.png` | Whichever feature you're proudest of and isn't covered above — Environments, Monitors, Mock Servers, or the GraphQL editor all work well here. |

## Guidelines
- Use placeholder/dummy data — fake names, `example.com` URLs, no real
  tokens, passwords, or production values visible.
- PNG, reasonably sized (under ~1–2 MB each keeps the repo light).
- Crop to the relevant window/panel rather than the whole desktop —
  keeps focus on the app, not your taskbar or other windows.
